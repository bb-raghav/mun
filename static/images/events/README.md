# Event photographs

The existing `IMG_6131.JPG` file is the RNSIT MUN 2026 organising committee photograph. Keep it in this folder; it appears on the homepage and in the Past Conferences archive.

Place additional approved RNSIT MUN conference photographs here. Supported formats: JPG, JPEG, PNG and WEBP. The Flask app discovers them automatically.

Use filename prefixes to group photos in the event gallery: `opening-`, `committee-`, `delegate-`, `executive-board-`, `organising-team-`, `closing-` or `award-`. For example: `committee-session-01.jpg`.

The existing group photo has its own 2026 archive entry and is not repeated in the additional photo grid. Use individual portrait files in `static/images/members/` and update the `LEADERSHIP_2026` data in `main.py` when approved profile photos are available.
